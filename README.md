# NOCTIS // PRIVATE NETWORK

Реальный многопользовательский чат с авторизацией по логину и паролю без почты, комнатами и личными сообщениями.

## Запуск
Node.js 20+.

```bash
npm install
npm start
```

Открой http://localhost:3000. Для публичного запуска нужен VPS/хостинг с Node.js, HTTPS и поддержкой WebSocket. База SQLite хранится в `data/chat.sqlite`.

## Безопасность
Пароли хешируются bcrypt; доступ к приватным комнатам проверяется сервером. Это MVP, не E2EE-мессенджер. Перед публичным запуском нужны модерация, аудит защиты, резервные копии, лимиты запросов и управление сессиями. Без почты восстановление утраченного пароля не предусмотрено.

Архив полной версии также доступен в переписке.
